# peluanglaundry

Custom WordPress Theme for **Peluang Laundry** (Orchid Brand).

## 🚀 Overview
Tema WordPress custom modern, ringan, dan dioptimalkan untuk kecepatan tinggi (Core Web Vitals A+) serta konversi lead WhatsApp & Marketplace (Shopee / Tokopedia).

## 📁 Struktur Penting
- `wp-content/themes/peluanglaundry/`: Source code custom theme (templates, style.css, assets, template-parts).
- `plan.md`: Master plan arsitektur dan spesifikasi tema.

## 🛠️ Tech Stack
- WordPress 6.x
- Vanilla PHP & Custom WordPress Template Hierarchy
- Modern Vanilla CSS dengan Design Tokens
- Vanilla JavaScript (ES6+)
